## Agents

Every command in SolidCraft, from the sketch tools to the timeline, is callable by name with typed input and output. The buttons you click and the tools an agent calls are the same thing: through the in-app assistant, any MCP client, or the headless CLI.

## Panels

Drag any panel to any edge, split it, tab it, float it. Save the layout and switch between layouts in one click.

## SolidCore

No licensed kernel and no C++ dependency. SolidCore is built in-house, tested against reference parts, and runs in the browser as well as on the desktop.
